CLIENT ISSUE
During PDF upload, the progress component is partially hidden/clipped at the bottom of the protected-PDF field/product card.
The percentage and progress/status area exist and update, but the container does not expand correctly to show the full component.

CONFIRMED CSS CAUSE
Inspect the LIVE file:
wp-content/themes/vava-living-theme-ar-v1/assets/css/admin-selections.css

The protected PDF layout currently combines rules such as:
- .vava-selections-product-item { overflow:hidden; }
- .vava-protected-pdf-field { height:100%; }
- .vava-protected-pdf-field > .vava-media-field { min-height:100%; display:flex; flex-direction:column; }
- .vava-protected-pdf-field .vava-media-actions { margin-top:auto; }

The progress element is dynamically inserted in normal markup between the PDF dropzone and the action buttons. When it becomes visible, the fixed/full-height flex layout does not expand naturally and the outer product card clips the overflow.

Use the supplementary patch from the patches repository:
VAVA-Client-Fixes-Stage-02-Digital-PDF-Upload/patches/0003-fix-digital-pdf-progress-layout.patch

TARGET LIVE FILE
wp-content/themes/vava-living-theme-ar-v1/assets/css/admin-selections.css
