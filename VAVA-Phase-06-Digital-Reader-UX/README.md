# VAVA Phase 06 — Digital Reader UX

## Objective
Improve the frontend experience of the existing protected digital reader without changing PDF storage, processing, or security.

## Scope
- Reader UI
- Navigation controls
- Loading states
- Error handling
- Zoom/fullscreen UX
- Mobile responsiveness

## Out of Scope
- PDF lifecycle
- Security model
- Payments
- Booking
- Other VAVA phases

## Execution
Use OpenHands-Prompt.txt against the live `/public_html` installation with backups before changes.
