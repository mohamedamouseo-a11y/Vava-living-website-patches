CONFIRMED SOURCE DIAGNOSIS

The Paths VAVA admin section registry currently contains TWO section keys with the same FAQ label:

English:
'questions' => 'Frequently asked questions'
'faq'       => 'Frequently asked questions'

Arabic:
'questions' => 'الأسئلة الشائعة'
'faq'       => 'الأسئلة الشائعة'

The duplicate 'questions' section is redundant.

It previews the same:
$data['faq']['items']

that the canonical 'faq' section already edits.

Also, the editor controls contain a dedicated branch for:
'faq'

but no controls branch for:
'questions'

so the duplicate 'questions' section can fall through to unrelated controls.

The canonical section to KEEP is:
'faq'
